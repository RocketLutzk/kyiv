# KYIV Premium by HETMAN — промо-сайт

Дві версії одного сайту (зміст, кольори й шрифти однакові):

| Папка | Що це | Вага |
|---|---|---|
| [`3d/`](3d/) | Фільм пляшки на 1050 кадрів, програється при прокрутці. Відео розпаковується через WebCodecs (`media/film-lo.mp4` 960 px завжди, `media/film-hi.mp4` 1920 px на великих екранах); для старих браузерів — запасна послідовність WebP (`media/film-webp/`). | ~120 МБ у репозиторії, телефон завантажує ~14 МБ |
| [`3d-flow/`](3d-flow/) | Та сама 3D-версія, але фільм не переривається: усі блоки (відео, нагороди, коктейлі, де купити, контакти) йдуть поверх фільму в темних картках зліва. Медіа бере з `3d/media/`. | лише `index.html` |
| [`static/`](static/) | Без анімації прокрутки: фото з того самого 3D-рендеру, у блоці «Якість» — чотири 3D-петлі (`media/q-*.mp4`). | ~3 МБ |

`index.html` у корені — сторінка з посиланнями на обидві версії.

## Запуск локально
3D-версію потрібно відкривати через сервер (не подвійним кліком), інакше вона перемкнеться на запасний режим:

```
python -m http.server 8000
```
і відкрити http://localhost:8000/

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

## Інструменти
`tools/kyiv_quality_elements.py` — скрипт Blender (4.2+), що будує й рендерить чотири 3D-петлі блоку «Якість».

## Що ще потрібно від клієнта
- відео про Київ для блоку «Дух столиці» (зараз заглушка `media/film.mp4`);
- посилання на соцмережі та політику конфіденційності;
- пряме посилання на товар на Rozetka.
